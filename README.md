# Bank Account System

A Java application for managing bank accounts and their financial transactions. The system allows users to register accounts, process credit and debit transactions, update account balances, and store data in text files.

## Features

* Register bank accounts
* Support different account types
* Record credit and debit transactions
* Update account balances
* Validate account codes when processing transactions
* Search for accounts
* Sort account and transaction data
* Read and write data using `.txt` files
* Handle file-related exceptions

## Technologies

* Java
* Object-Oriented Programming (OOP)
* File Handling
* Arrays
* Sorting and Searching Algorithms

## Project Structure

The project is organized into classes responsible for account management, transactions, data processing, and file operations.

